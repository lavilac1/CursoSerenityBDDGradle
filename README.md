# Proyecto de Curso Serenity BDD 

Este es un proyecto de automatización usando Serenity BDD con Java, Gradle y Cucumber.

## Tecnologías usadas

- Java 11
- Gradle 5.6.4
- Serenity BDD
- Cucumber
- Selenium WebDriver

## Estructura del proyecto
src/
main/
java/
test/
java/
features/
stepDefinitions/

## Cómo ejecutar

```bash
./gradlew clean test aggregate
```
